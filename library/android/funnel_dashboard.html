PROXY  This shows unique users who ever tuned to each channel (from channelLeaderboard), not strictly the first channel. It's a close proxy because the app boots into the last/default channel — &TV International (ch 1) dominates at — users, almost certainly the default landing channel. For the true metric, take the first playback_start per uid:
SELECT ch, name, count(DISTINCT uid) users FROM ( SELECT uid, ch, name, ROW_NUMBER() OVER (PARTITION BY uid ORDER BY ts) rn FROM events WHERE event='playback_start' ) WHERE rn=1 GROUP BY ch, name ORDER BY users DESC;
