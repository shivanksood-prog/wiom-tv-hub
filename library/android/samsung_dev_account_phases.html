Wiom TV · Samsung Smart TV

Developer Account → Samsung Approval → Signed App

Five phases from zero to the Samsung TV store. Signing happens twice: once by us (dev & upload), once by Samsung (at release).

The one thing to know: Phases 1–2 need no approval from anyone — the app is signed and running on our own Samsung TV in about an hour. The only genuinely uncertain step is Phase 4: India distribution requires a Samsung partnership contract, which is a BD motion, not paperwork.
1

Samsung Account

Do now · 10 min
Owner: us · Cost: free · Approval: none
  1. Create a Samsung account at account.samsung.com using a company-controlled email (e.g. samsung@wiom.in) — never a personal one.
  2. Verify email. This single account powers every later phase: certificates, Seller Office, the partnership.
One company account that everything chains from
2

Dev Certificates — Sign It Ourselves

Do now · 30–45 min
Owner: us · Cost: free · Approval: none · Tool: Tizen Studio Certificate Manager
  1. Get the TV's DUID: TV → Apps → type 12345 → Developer-mode popup shows it.
  2. Certificate Manager → new profile, type Samsung (plain "Tizen" type won't install on a real Samsung TV).
  3. Author certificate — org = Wiom Broadband Pvt Ltd, sign in with the Samsung account → author.p12.
  4. Distributor certificate — level Public, enroll the TV's DUID (up to ~50 TVs) → distributor.p12.
  5. Name the profile WiomTV; put the issued package ID into config.xml.
  6. Build & install: tools/build.sh → signed WiomTV.wgt → TV_IP=… tools/deploy.sh.
⚠ Back up author.p12 + password like a production keystore. Every future update — including store releases — must be signed with this exact certificate. Losing it is the Play-Store upload-key incident all over again.
App signed & running on our Samsung TV — hardware validation unblocked
3

Seller Office — Public Seller

Parallel · 1–2 days
Owner: us + finance (entity docs) · Cost: free · Approval: automatic
  1. Sign in at seller.samsungapps.com/tv with the same account → accept terms → Public Seller.
  2. Create the company group (Membership menu): legal entity + business registration details. Rights attach to the group, not the individual.
⚠ Public Seller can launch apps in the United States only. Useful as a dry run of Samsung's pre-test + review pipeline — not for reach in India.
Submission pipeline available; US dry-run listing possible
4

Partner Seller — The India Gate

BD motion · weeks–months
Owner: founder-level · Cost: offline contract · Approval: Samsung Content Manager
  1. Seller Office → Membership → Partnership — the form requires an assigned Samsung Content Manager's email.
  2. No contact yet → request one via the 1:1 Q&A menu, and in parallel work any Wiom ↔ Samsung India BD channel (the warmer path).
  3. Sign the offline contract with Samsung HQ / Samsung India.
  4. Content Manager approves → group becomes Partner Seller → India + other countries unlock.
⚠ This is a content-rights review. The store build must ship a Green-only channel lineup (a config edit, not a code change) — walking in with unlicensed feeds ends the conversation.
✦ Prep that strengthens the pitch: app validated on real hardware (Phase 2), Android-side adoption numbers, Green lineup ready.
India distribution unlocked
5

Submission — Samsung Signs & Ships

After 4 · 2–4+ weeks review
Owner: us · Samsung's release signing: automatic on approval
  1. Applications → create app entry (name, type = video, default language).
  2. Upload the .wgt (signed with our author cert) → automated pre-test runs instantly; fix flags.
  3. Listing assets: icons 1920×1080 + 512×423, screenshots, descriptions, content rating, privacy-policy URL, countries, TV model groups. Optional beta track first.
  4. Request release → human review + on-device verification. Pre-empt the Return-key question: document our double-press-exit in review notes.
  5. On approval, Samsung re-signs the package with its distribution certificate and publishes — the final signature, automatic once approved.
Updates repeat steps 2→4 — always with the same author certificate. Channel lineup changes need no store release (remote config); only code changes do.
Wiom TV live on Samsung's store
