Wiom TV Install Agent · v1.0-pilot · GUIDED build

The guided installer — zero permission prompts

We pivoted away from accessibility auto-tap after the permission wall (Play Protect + the greyed-out "restricted settings"). This build asks for nothing — it just finds the TV, shows the 3 taps, and opens Google Play. The household makes the taps in an app they were already guided through.

0 permission prompts No accessibility No overlay Just a sideload + 3 guided taps
Why we pivoted

The accessibility permission only ever bought us tapping Install for the user — it unlocked no extra capability (Google blocks programmatic TV install regardless). But it demanded sideload → Play Protect warning → accessibility grant → "allow restricted settings." For a non-tech base that chain is more friction than the 3 taps it removed. So we keep the guidance, drop the automation.

✕ Auto-tap build

  • Sideload + unknown sources
  • Play Protect warning
  • Accessibility grant
  • "Allow restricted settings" unblock
  • ~1 tap, but brittle selectors

✓ Guided build (now)

  • Sideload + unknown sources
  • No other prompts at all
  • Finds the TV, shows the 3 taps
  • Opens Play; user taps Install
  • Catches wrong-device installs
