Per-variant cohort funnel
intro_shown→ genre_select / start_direct→ intro_complete→ activated (≥60s)→ D1→D7
Cohort tracking. Sticky variant (hash of uid) stamped on every event + first-seen logged in devices. Cohort = new uids in bucket A, by first-seen day. /api/cohorts + /api/stats gain a variant filter so every headline metric — activation avg time/user switches — splits A vs B vs C. Path mix (genre vs सीधे शुरू) is read from intro_complete.via.
Why no skip: a skip leaves the user stranded with no signal — a silent activation loss we couldn't attribute. सीधे शुरू करें keeps the already-playing channel (the standard flow) and logs it, so the funnel has no dark leak.

Per-variant cohort funnel
intro_shown→ genre_select / anything / rail_ignored→ intro_complete→ activated (≥60s)→ D1→D7
Cohort tracking. Same sticky variant + devices first-seen model as A1, same variant-filtered /api/stats & /api/cohorts. The extra read for A2 is rail engagement rate = 1 − (rail_ignored ÷ intro_shown) — directly answers "is a non-blocking nudge enough, or does orientation need to block (A1)?"
Same no-dead-end rule: the rail leads with कुछ भी so even a passive user has a one-tap path to good content — and rail_ignored makes the silent-pass-through visible instead of lost.
