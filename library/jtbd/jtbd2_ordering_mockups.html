Reorder channels within a genre — popularity → personal

No onboarding, no new screen. We just change the sort order of the existing channel list inside each genre. Same genre (फिल्में) shown three ways below. The order is the single source of truth for the channel A1 lands you on, the guide, and the up/down zap sequence.

// within each genre, sort channels by score (desc)
score(ch) = POP[ch] // global watch-min, last 7d → the prior
         + k · MINE[ch] // this uid's own dwell → 0 at cold-start
cold-start (no history) → MINE=0 → pure popularity
over visits         → your channels rise → becomes yours

How we measure the ordering — one new field

Add rank to tunetune + landing
The only new instrumentation: stamp the channel's position in its ordered genre on every tune/landing. Lets us prove the sort surfaces better channels.
{ variant:"B", event:"tune", ch:206, cat:"movies", rank:1, dur:2520 }
Dwell-by-rank curvethe proof
Plot average dwell & tune-share by rank, per variant. If ordering works, rank-1 channels capture more watch-time and more tunes in B than in C — i.e. the top of the list is genuinely the right channel.
