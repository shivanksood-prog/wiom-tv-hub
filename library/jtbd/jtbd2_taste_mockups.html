Wiom TV · JTBD-2 — "Know me, get me what I like" · Mobile

Four ways to learn taste — and lead with it

The personalization job, mocked the same way as JTBD-1: phone screen + the exact analytics each emits + the per-variant cohort funnel. Pick one (or the B1+B3 combo) to become Arm B.

The cold-start tension: on a true first launch there is no history. So options split into ASK (B1 — capture taste up front), INFER (B2 — learn silently, serve on return), DEFAULT-SMARTER (B3 — auto-land favourite), and BORROW (B4 — start from what's popular, personalize as data accrues).

B1 · One-tap taste capture

Recommended — Arm B

ASK. First launch: pick a few you like (multi-select), tap once → we build a taste profile, personalize the lineup, and land on the best match. The only option with a visible, testable first-launch difference — the honest test of the personalization JTBD.

B2 · Silent learn → serve on return

Alt — Arm B

INFER. No first-launch UI (day 1 = control). We log session-1 dwell/zapping, then on the return visit lead with an "आपके लिए" row built from what they actually watched. Zero friction — but invisible on day 1, so it can only win on retention.

B3 · Auto-land on favourite

Cheapest · compounder

DEFAULT-SMARTER. Pure behavioural, no UI to build. On return, auto-land on the user's highest-dwell channel instead of channel 1 — with a dismissible toast so it never feels like a hijack. Strong control-beater on return; tiny effort.

Per-variant cohort funnel (return)

Cohort tracking. Same sticky variant. The make-or-break read is override rate (autoland_override ÷ autoland) — low = we're landing them right (rising dwell-per-switch, the "better channels" metric).
Best as a companion to B1: B1 captures taste explicitly, B3 acts on accumulated dwell — together they make Arm B sharper every visit.

B4 · Popularity → personal blend

Alt — solves cold-start

BORROW. Cold-start has no personal data — so first launch leads with "अभी ट्रेंडिंग" (most-watched now, from our leaderboard), then blends in personal as history accrues. Good defaults from day 1; "popular" ≠ "my taste" is the risk.
